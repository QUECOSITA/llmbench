# Fix Malformed Serving Command (500 → "Failed to fetch") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make running a benchmark for models whose README contains ANSI-C/quoted flag values (e.g. `--reasoning-budget-message $'...'`) work — and surface any real backend error to the frontend instead of "Failed to fetch".

**Architecture:** Two fixes. (A) Root cause: `readme_parser.extract_flags` truncates ANSI-C `$'...'` values at the first space, producing an unclosed quote in the generated serving command; `shlex.split` then raises `ValueError: No closing quotation` → 500. Fix by decoding quoted values fully in the parser and shell-quoting values that need it when the command string is built, then converting any residual `ValueError` into a clean 422 `bench_error`. (B) Masking: unhandled 500s are generated by Starlette's `ServerErrorMiddleware` *outside* `CORSMiddleware`, so the response has no `Access-Control-Allow-Origin` and the browser hides the real message as `TypeError: Failed to fetch`. Fix by registering a generic exception handler that adds CORS headers.

**Tech Stack:** Python 3.12, FastAPI, Starlette, `shlex`/`re`, pytest.

Add below `_VALUE_TERMINATORS` in `backend/app/readme_parser.py`:

```python
_QUOTE_OPENS = ("$'", '$"', "'", '"')

_ANSI_ESCAPES = {
    "a": "\a", "b": "\b", "e": "\x1b", "f": "\f",
    "n": "\n", "r": "\r", "t": "\t", "v": "\v",
    "\\": "\\", "'": "'", '"': '"',
}


def _decode_ansi_escape(text: str, i: int) -> tuple[str, int]:
    """Decode the ANSI-C escape beginning at text[i] (a backslash)."""
    if i + 1 >= len(text):
        return "\\", 1
    ch = text[i + 1]
    if ch in _ANSI_ESCAPES:
        return _ANSI_ESCAPES[ch], 2
    if ch == "x":
        j = i + 2
        hexdigits = ""
        while j < len(text) and len(hexdigits) < 2 and text[j] in "0123456789abcdefABCDEF":
            hexdigits += text[j]
            j += 1
        if hexdigits:
            return chr(int(hexdigits, 16)), j - i
    if ch in "01234567":
        j = i + 1
        octdigits = ""
        while j < len(text) and len(octdigits) < 3 and text[j] in "01234567":
            octdigits += text[j]
            j += 1
        return chr(int(octdigits, 8)), j - i
    return "\\" + ch, 2


def _consume_quoted_value(text: str, start: int) -> tuple[str | None, int, bool]:
    """If text[start:] begins a quoted value, return (decoded_value, end_after_quote,
    unterminated). unterminated is True only when a quote opened but never closed."""
    while start < len(text) and text[start].isspace():
        start += 1
    rest = text[start:]
    opener = next((op for op in _QUOTE_OPENS if rest.startswith(op)), None)
    if opener is None:
        return None, start, False
    ansi = opener in ("$'", '$"')
    qchar = opener[-1]
    i = len(opener)
    out: list[str] = []
    while i < len(rest):
        ch = rest[i]
        if ansi and ch == "\\":
            decoded, consumed = _decode_ansi_escape(rest, i)
            out.append(decoded)
            i += consumed
            continue
        if ch == qchar:
            return "".join(out), start + i + 1, False
        out.append(ch)
        i += 1
    return None, start, True
```

```python
_SHELL_SPECIALS = " \t\n\"'\\$`"


def _shell_arg(value: str) -> str:
    if any(ch in value for ch in _SHELL_SPECIALS):
        return shlex.quote(value)
    return value


def _flag_tokens(flags: dict[str, str]) -> list[str]:
    tokens: list[str] = []
    for flag, value in flags.items():
        tokens.append(flag)
        if value and value != flag:
            tokens.append(_shell_arg(value))
    return tokens
```

```python
    async def unhandled_exception_handler(request: Request, exc: Exception) -> JSONResponse:
        logger.exception("Unhandled exception: %s", exc)
        origin = request.headers.get("origin")

            content={

            },
            headers={"Access-Control-Allow-Origin": allow_origin},
        )
```
